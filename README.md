# Projeto-integrador-ll
Biblioteca Fácil
Problema:
A biblioteca da escola pode ter dificuldades para organizar os livros, empréstimos e devoluções. Além disso, os alunos podem ter dificuldade para saber quais livros estão disponíveis no momento para ler.
Solução:
O Biblioteca Fácil será um sistema para organizar os livros da biblioteca escolar. Nele os alunos poderão pesquisar livros e ver se está disponível e o responsável pela biblioteca poderá cadastrar livros, registrar empréstimos e devoluções e acompanhar o histórico.

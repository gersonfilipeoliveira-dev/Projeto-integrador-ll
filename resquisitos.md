Requisitos Funcionais

01: Cadastrar livros.
02: Editar e excluir livros.
03: Pesquisar livros por nome, autor ou categoria.
04: Consultar a disponibilidade dos livros.
05: Cadastrar alunos.
06: Registrar empréstimos.
07: Registrar devoluções.
08: Consultar o histórico de empréstimos.

Requisitos Não Funcionais

01: O sistema deve ser simples e fácil de usar.
02: O sistema deve proteger os dados dos usuários.
03: As pesquisas devem apresentar resultados rapidamente.
04: O sistema deve funcionar em computadores e celulares.
05: Apenas usuários autorizados poderão cadastrar, editar ou excluir informações.
